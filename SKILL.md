# Fixtures Faceless Shorts

## What this project is
An executable blueprint for a **faceless YouTube Shorts channel** publishing 5–7 daily vertical videos (15–60s, 9:16) in **Tamil / Malayalam / Hindi**, plus an English subtitle layer. Seven content pillars:
Cinema (15%) · Spiritual (15%) · Language/Culture (12%) · Automobile (14%) · Cooking (13%) · AI Education (14%) · Investments (13%).

## How an AI agent uses this repo
1. Read `README.md` — quick overview, <30 seconds.
2. Read `TASK.md` — the autonomous workflow controller.
3. Read `PLAN.md` only when you need detail.
4. Before generating any script, read `scripts/template.md`.

## Where the work lives
- `PLAN.md` — full blueprint (7-pillar matrix, daily rotation, audio, trend radar, production SOP, compliance, 30-day roadmap)
- `scripts/` — copy-paste script template + hook library
- `audio/` — music library (placeholder)
- `assets/` — artwork/thumbnail placeholders (placeholder)
- `logs/` — one handoff summary per day

## How to produce a short (agent checklist)
- [ ] Pick pillar + language (Mon–Sun table in `TASK.md`)
- [ ] Write hook (0–1.5s) + VO (40–70 words)
- [ ] Pick visual (single concept, max 3 shots)
- [ ] Write caption (2–3 lines + English subtitle)
- [ ] Add audio (library track + pillar→audio match + -14 LUFS mastering)
- [ ] Package upload metadata (title, 6 tags, 2-line description, thumbnail concept, certifications)

## Rules
- Never use "guaranteed returns" for finance — add "not financial advice."
- Food safety: cool storage, don't leave rice out.
- Never lift full movie dialogue as your own — 5–10s clips + transform meaning.
- Music must be royalty/clearance-free (or set certifications "No").
- Never promise high returns. Cite sources for all numbers.

## Success metrics (day 30)
1,000 total views · 3 shorts with ≥35% avg watched → then double posting cadence.
